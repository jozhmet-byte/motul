# Reglas y Preferencias del Proyecto (MOTUL)

## Eficiencia y Flujo de Trabajo
1. **Trabajar directo y al grano:** Evitar sobre-procesamiento o pasos redundantes para tareas simples y directas.
2. **Uso estricto de capturas y navegador:** NO tomar capturas de pantalla innecesarias ni abrir o manipular el navegador para cambios simples o evidentes. Únicamente emplear herramientas de navegador/capturas cuando el usuario lo solicite expresamente o sea estrictamente indispensable para validar layouts complejos que no puedan comprobarse directamente en código.
3. **Respuestas ágiles y concisas:** Presentar cambios de forma clara, directa y sin rodeos.
